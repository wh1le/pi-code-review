# 0.9.0

pi-hunk now does one thing: orchestrates explicit Hunk review checkpoints for Pi.

## Breaking changes

- Removed custom `edit` and `write` overrides and all custom Pi diff presentation. Pi now uses its built-in tool behavior and presentation unchanged.
- Removed appearance presets, syntax highlighting, color/symbol controls, line furniture, preview UI, and related configuration.
- Removed `diff` and `shiki` runtime dependencies plus unused Pi peer dependencies.
- `/hunk configure` now manages only Hunk enablement and binary path. Saving rewrites `.pi/hunk.json` to Hunk-only schema; former appearance keys are ignored when loading.

## Preserved

- `/hunk status`, `/hunk review`, `/hunk submit`, `/hunk abandon`, and `Ctrl+Shift+H` retain checkpoint behavior.
- Existing side-pane reuse and same-terminal Hunk handoff remain unchanged.
- Complete review exports, exact human-note delivery, explicit empty approval, stale-review refusal, Git fallback, untracked-file coverage, session restoration, and append-only checkpoint journal remain covered by checks.
- Successful Pi `edit` and `write` results are observed without overriding tools, preserving Hunk navigation toward most recently changed file.
- Version 1 and 2 checkpoint journal entries remain readable. New entries use version 3 without obsolete presentation metadata.

## Migration

No command migration required. Existing Hunk settings under `hunk.enabled` and `hunk.binary` continue to load. Run `/hunk configure` once to replace old project config with Hunk-only schema.
